## Вбудований веб-сервер {#builtin_web_server_title}

З PHP 5.4 або новішої версії ви можете розпочати роботу над PHP без встановлення та налаштування повноцінного веб-сервера.
Щоб запустити сервер, запустіть таку команду з вашого терміналу в кореневій веб-версії проекту:

{% highlight console %}
> php -S localhost:8000
{% endhighlight %}
